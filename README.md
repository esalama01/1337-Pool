# 1337-Pool

My exercises and rushes from the **July 2026 Piscine (Pool)** at **1337 Khouribga** — the intensive, project-based selection month that precedes the core curriculum at 1337/42 network schools.

## About the Piscine

The Piscine is a month-long coding immersion where students solve daily C exercises, sit weekly exams, and complete team "Rush" projects — all without lectures, using peer learning and the school's Moodle-based evaluation system. It's designed to test autonomy, problem-solving under pressure, and the ability to learn fast with minimal guidance.

- **School:** 1337 Khouribga
- **Cursus:** C Piscine
- **Grade:** Piscinier
- **Language:** C (98.9%)
